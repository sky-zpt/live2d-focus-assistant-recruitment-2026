# math-model-project
my first project for math model test
## 名称 ：
模拟经营
## 用途 ：
通过控制台输入数字来实现制造，卖货，休息，退出等功能，以此赚取资金，达成目标。
## 主要功能 ：
制造，卖货（定价；依据天气，声誉和随机事件决定的客流量），休息（随机天气和事件），银行的贷款与还款，数据存档与清档，破产和无尽模式）
## 流程 ：
运行->状态板->运营->破产或达成目标。
## 环境与运行 ：
PYthon 3.10及以上；终端输入‘Python main.py’
## 手动验证 ：
拦截非数字符号和负数的函数，银行的贷款还款体系以及与破产判定的关系，单天刷钱的逻辑问题，濒临破产且银行贷款无法解决导致的游戏死循环，一些颠倒的逻辑问题，变量的范围判定。
## 未完成及限制的想法 ：
雇佣玩法（不同的店员由于技术和制作时间的原因影响客流量），顾客评价（增加一种加或减声誉的途径），增加随机事件‘设备损坏’（与银行贷款联动，以及会影响客流量），更自由的网红探店（加入贿赂玩法，且不同粉丝体量带来的声誉增加或减少不同），利息计算，有图），小店地址的选择（根据不同的地址改变不同随机事件触发概率，以及其他金额等变化），升级系统（设备的效率和故障率，店员效率等），竞争模式
## AI使用 :Deepseek，豆包
1.清存档的加入。
2.增加游戏呼吸感的设计（如回到主循环清屏，以及按下回车再继续）
3.游戏中的数值
4.一些逻辑问题（如，忽略程序运行顺序导致的数值计算错误，和内外分支的变量识别问题等）
